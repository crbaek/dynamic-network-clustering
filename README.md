Official implementation of the paper "Dynamic spectral co-clustering of directed networks to unveil latent community paths in VAR-type models" by Younghoon Kim and Changryong Baek.
This repository provides a framework to detect group structures within complex, directed networks. 
The models track how hidden communities evolve across different time periods, allowing users to observe when groups split, merge, or remain stable. 
Applications include analyzing time-series data like macroeconomic trends and stock index movements.
